# Troubleshooting

## Common issues

### Dependency installation failures

- Recreate the virtual environment.
- Upgrade `pip` before installing requirements.
- Confirm that the Python version matches the project requirements.

### Missing environment variables

- Check `.env` configuration.
- Ensure required API keys are loaded before running the app.

### Audio input problems

- Verify microphone permissions.
- Test the audio device in your OS settings.
- Make sure the correct input device is selected in the app.

### Project setup confusion

- Use this repo-level documentation hub as the starting point.
- Check the voice-line project files first if issues are isolated to the assistant subsystem.
